# evaluation

Artefacts required by the submission contract.

- `usage_report.md` — token usage and cost for the **final full-dataset run**
  that produced the root-level `output.csv`. Must cover model providers and
  names, model calls, input and output tokens, total and average tokens per
  request, and estimated total and per-request cost; per-model and overall
  totals when more than one model is used. Generated by `src/run.py`, not
  written by hand.
- Self-scoring output against `dataset/sample_requests.csv` (phase 2+).

No API keys, credentials, or sensitive configuration in this folder.
