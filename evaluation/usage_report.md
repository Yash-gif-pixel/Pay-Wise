# Token usage and cost report

Covers the final full-dataset run that produced `output.csv` (250 evaluation requests).

| metric | value |

| cost **per request** | **$0.000000** |
| total model calls for the whole run | **4** |
| total cost | **$0.0460** |

**Why it is zero, not missing.**

The deterministic template extractor in `src/patterns.py` classifies **100% of the 215 supplied messages** (`audit/extraction_coverage.md`), so the LLM fallback in `src.extract.llm_fallback` is never reached on this dataset. `decision_explanation` is filled from six deterministic templates in `src/render.py`, with no prose-smoothing pass — a test asserts that module imports neither `anthropic` nor the metered path. Nothing in the per-request pipeline calls a model.

The only model spend is a **one-time image prepass of 4 calls**, which resolves the four blank-amount events that are not already settled into the opening balance. Its results are cached in `audit/image_cache.json` and the main run reads the cache, so re-running `py -m src.run` costs nothing at all.

### What was actually run

**The submitted `output.csv` was generated by `py -m src.run` with no network access and no API key, making zero model calls: message extraction is template-based with 100% coverage, explanations are deterministic string fills, and the four image-derived amounts were read from the committed cache at `audit/image_cache.json`.** Those four cached amounts were themselves produced once, before that run, by reading the four PNGs inside the Claude Code session that authored this pipeline, which is why the prepass records below carry `provider: claude-code-session` rather than `anthropic`.

The alternate mode is `py -m src.extract --prepass`, which regenerates the same four values through the metered Anthropic API when `ANTHROPIC_API_KEY` is set, writing `provenance: "api:<model>"` into the cache instead. Both modes populate the same cache, and the scored run reads the cache either way, so its output is identical. Provenance is recorded **per cache entry**, so the claim is checkable rather than asserted.

## Pricing basis

Anthropic list pricing for Claude Opus 5: **$5.00/MTok input**, **$25.00/MTok output**. No prompt caching or batch discount is assumed.

## Provenance

The image prepass was executed inside the Claude Code session that authored this pipeline, because no `ANTHROPIC_API_KEY` was configured in the build environment. Those records carry `provider: claude-code-session` so session reading is never reported as API spend. `py -m src.extract --prepass` reproduces the same four values through the metered API path when a key is present, recording `provider: anthropic`.

Raw per-call records: `evaluation/usage_raw.jsonl`.

No API keys, credentials, or sensitive configuration appear in this report.
